# Анализ влияния сна и экранного времени на успеваемость и стресс студентов

Это разведочный анализ данных (EDA) данных о продолжительности сна, экранном времени, уровне стресса и GPA. В рамках анализа стоит цель найти закономерности и дать им предположительное объяснение.

### Ключевые вопросы проекта:
- Есть ли закономерность между количеством сна и стрессом?
- Есть ли закономерность между величиной экранного времени и количеством сна?
- Есть ли закономерность между величиной экранного времени и успеваемостью?

### Данные
Источник: https://www.kaggle.com/datasets/uditjain13/student-sleep-screen-time-and-mental-health-2026

Размер выборки: 3000 человек 

Все переменные обладают числовым, строковым или булевым типом

Пропуски в данных отсутствуют 

### Результаты
- Корреляция между продолжительностью сна и уровнем стресса составляет -0.496. Это умеренная обратная корреляция
- Корреляция между экранным временем и сном составляет -0.587. Это умеренно сильная обратная корреляция
- Корреляция между экранным временем и GPA составляет  -0.469. Это умеренная обратная корреляция

### Ограничения

- Корреляция не обещает причинности наличие причинно-следовательной связи 
- На все три связи может влиять общий фактор, который не был рассмотрен-например, учебная нагрузка в период сбора данных
